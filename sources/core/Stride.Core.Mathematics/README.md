# Stride.Core.Mathematics

Math library for the Stride game engine. Provides high-performance math types optimized for real-time 3D applications.

- Vectors: `Vector2`, `Vector3`, `Vector4`, `Int2`, `Int3`, `Int4`
- Matrices: `Matrix` (4×4), `Matrix3x3`
- Rotation: `Quaternion`, `AngleSingle`
- Colors: `Color`, `Color3`, `Color4`, `ColorHSV`
- Bounding volumes: `BoundingBox`, `BoundingSphere`, `BoundingFrustum`, `OrientedBoundingBox`
- Geometric primitives: `Ray`, `Plane`, `Viewport`, `Rectangle`, `RectangleF`
