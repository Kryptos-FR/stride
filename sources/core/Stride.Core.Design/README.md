# Stride.Core.Design

Design-time utilities and helpers for the Stride editor (Game Studio). Not intended for use at game runtime.

- `AbsoluteId` — globally unique identifier combining asset and object IDs
- `PackageVersion` — semantic versioning for Stride packages
- `NamingHelper` — code name generation and uniqueness utilities
- Type converters and reflection helpers used by the property grid
- `ObjectCache` — object pooling for editor performance
