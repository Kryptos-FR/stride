# Stride.Core.Serialization

Binary serialization framework for the Stride game engine. Supports cross-object references, inheritance, and streaming.

- High-performance binary serialization with object graph tracking
- Content manager integration for asset loading and reference counting
- Streaming support for large resource loading
- Serializer auto-generation via `[DataContract]` / `[DataMember]` attributes
- Extensible serializer registry for custom type serialization
