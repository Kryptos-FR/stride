# Changelog

## 0.1.0

Initial release.

- Asset navigation (Ctrl+Click on `GUID:AssetName` references)
- Entity reference navigation (`ref!! GUID`)
- Source path navigation and clickable links
- Hover tooltips for assets, entities, source paths, and scripts
- Broken link diagnostics with auto-resolution
- YAML syntax highlighting for all `.sd*` file types
- Quick find command to search assets by name
- Opt-in script navigation to C# source files
- Opt-in back-links with CodeLens reference counts
- Opt-in full workspace broken link scan
