# Stride.SpriteStudio.Runtime

Runtime support for OPTPiX SpriteStudio skeletal animations in the Stride game engine.

- `SpriteStudioComponent` — entity component that plays back a SpriteStudio animation sheet
- `SpriteStudioProcessor` / `SpriteStudioRendererProcessor` — ECS systems for update and rendering
- `SpriteStudioSheet` / `SpriteStudioNode` — runtime animation data structures
- Supports SpriteStudio cell maps, bones, and animation curves
