# Stride.SpriteStudio.Offline

Editor-side asset import and compilation for OPTPiX SpriteStudio animations in Stride. Used during the asset build pipeline; not included in game runtime packages.

- `SpriteStudioImporter` — imports `.ssproj` SpriteStudio project files into Stride assets
- `SpriteStudioAnimationAssetCompiler` / `SpriteStudioModelAssetCompiler` — compile imported data into binary runtime assets
