# Stride.BepuPhysics.Debug

Debug visualization tools for `Stride.BepuPhysics`. Renders collision shapes and physics state overlays directly in the scene for development and debugging.

- `DebugRenderComponent` — attaches physics shape visualization to an entity
- `DebugRenderProcessor` — engine subsystem that generates wireframe overlays for all active colliders
- Configurable per-shape color coding (dynamic, static, sleeping)
