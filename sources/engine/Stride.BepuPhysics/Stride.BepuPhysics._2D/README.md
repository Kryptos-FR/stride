# Stride.BepuPhysics._2D

2D rigid body physics extension for Stride, built on top of `Stride.BepuPhysics`. Constrains simulation to the XY plane for 2D game scenarios.

- `Body2DComponent` — 2D rigid body with position and rotation locked to a plane
- `Simulation2DComponent` — scene-level 2D simulation settings
- Reuses the full Bepu collision shape library in a 2D context
