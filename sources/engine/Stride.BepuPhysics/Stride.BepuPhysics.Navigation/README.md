# Stride.BepuPhysics.Navigation

Navigation mesh and pathfinding integration for `Stride.BepuPhysics`. Enables AI agents to navigate scenes while respecting physics collision geometry.

- Integrates with the [DotRecast](https://github.com/ikpil/DotRecast) navigation library
- `NavigationState` — per-agent navigation state and path following
- Automatic navigation mesh generation from Bepu static collision shapes
