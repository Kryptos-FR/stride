# Stride.UI

Retained-mode UI framework for the Stride game engine. Enables building in-game menus, HUDs, and interfaces using a layout system similar to WPF.

- `UIElement` — base class for all UI controls with layout, input, and styling
- Layout panels: `Canvas`, `StackPanel`, `Grid`, `UniformGrid`
- Controls: `Button`, `TextBlock`, `EditText`, `ImageElement`, `ScrollViewer`, `Slider`
- Event system for pointer, keyboard, and touch interactions
- `UIComponent` / `UISystem` — integration with the ECS and rendering pipeline
